# My Portfolio Website

A personal portfolio website showcasing my projects, skills, and experience.

🔗 **Live Site:** [yeadonayeashenafi.vercel.app](https://yeadonayeashenafi.vercel.app)

## Overview

This repository contains the source code for my personal portfolio, built to highlight my work as a computer science student, including selected projects, technical skills, and ways to get in touch.

## Features

- Responsive design that works across desktop, tablet, and mobile
- Project showcase with descriptions, tech stacks, and links to live demos/repos
- About section with skills and experience
- Contact form / contact links
- Smooth navigation and animations

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (or React / Vue / etc.)
- **Styling:** Tailwind CSS / Sass / CSS Modules
- **Deployment:** Vercel
- **Other tools:** Authentification API for admin page

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yeadonaye/portfolio.git
   cd portfolio
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Run the development server
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
```
